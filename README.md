# BeatFlow

BeatFlow es un sitio web de una plataforma de musica. El proyecto cuenta con diferentes paginas para navegar por contenido musical, consultar los planes, revisar la biblioteca e iniciar sesion.

## Descripcion

El proyecto fue realizado para crear una pagina web de una plataforma de musica llamada BeatFlow.

La idea de BeatFlow es que los usuarios puedan descubrir musica nueva y encontrar canciones que sean de su gusto. Tambien cuenta con recomendaciones de la semana y canciones que pueden gustarle al usuario dependiendo de lo que haya escuchado anteriormente.

La plataforma busca que sea facil encontrar musica diferente, descubrir nuevos artistas y volver a encontrar canciones que el usuario ya habia escuchado en algun momento.

El sitio cuenta con un menu principal con las siguientes secciones:

- Inicio
- Novedades
- Planes
- Biblioteca
- Iniciar Sesion

Cada pagina tiene informacion relacionada con la plataforma y estan conectadas entre si mediante el menu de navegacion.

## Paginas Desarrolladas

### Inicio

Es la pagina principal del sitio. Desde aqui se puede acceder a las demas secciones de BeatFlow mediante el menu.

Tambien se muestran algunas recomendaciones para que el usuario pueda conocer musica nueva y encontrar canciones que podrian ser de su gusto.

### Novedades

En esta pagina se muestra contenido relacionado con las novedades musicales, como nuevos lanzamientos, canciones recientes y recomendaciones de la semana.

La idea es que el usuario pueda encontrar musica diferente y conocer nuevos artistas o canciones que todavia no haya escuchado.

### Planes

Aqui se muestran los tres diferentes planes disponibles de BeatFlow y la informacion correspondiente a cada uno.

### Biblioteca

La biblioteca permite consultar diferentes partes de la coleccion musical del usuario.

Cuenta con:

- Albumes recientes
- Artistas guardados
- Listas de reproduccion

En esta seccion tambien se puede encontrar musica que el usuario ya habia escuchado anteriormente y que podria querer volver a escuchar.

### Iniciar Sesion

Esta pagina cuenta con un formulario para iniciar sesion utilizando correo electronico o ID de Apple y contraseña.

Tambien tiene una opcion para iniciar sesion con iPhone.
